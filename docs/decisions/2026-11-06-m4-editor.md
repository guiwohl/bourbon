# 2026-11-06 — Milestone 4: editor

Decided by Claude during the autonomous run; review at the UI pass.

Spec source: the "Editor" rows of [feature scope](2026-11-06-feature-scope.md).

| # | Topic | Decision |
|---|---|---|
| 1 | View modes | Segmented switch under the editor header: Edit, Side-by-side, Preview (`view-mode-*` buttons). One app-wide mode, default Edit, kept when switching notes. `Ctrl+E` cycles Edit, Side-by-side, Preview (bound with and without the `Input` key context, because inputs bind `Ctrl+E` to end of line). Changing mode focuses the editor, or the root view in Preview so shortcuts keep working |
| 2 | Preview renderer | gpui-component `TextView::markdown`. GFM tables render natively |
| 3 | Task checkboxes | The library checkbox reports no clicks. The preview therefore splits the body into blocks (`preview_blocks`): runs of ordinary Markdown go to `TextView`; every task line (`-`, `*`, `+` bullet followed by `[ ]` or `[x]`, any indent, outside code fences) becomes our own row with a clickable `Checkbox` and the label rendered as inline Markdown. Known limit: a task item continued on several lines, or a block nested under a task, renders as separate blocks |
| 4 | Toggling | Pure `tasks` module returns a `TextEdit` (byte range and text): flips the single character between the brackets. The editor applies it through its normal replace, keeps the cursor, and restarts the 500 ms autosave, so a preview click saves exactly like typing |
| 5 | `Ctrl+Enter` | In the body editor: toggles the task on the cursor line, or turns a plain `-`/`*`/`+` list line into `- [ ]`. On any other line it does nothing (it does not insert a newline) |
| 6 | Note links | Typing `[[` opens an inline suggestion list above the editor (`link-suggestions`), up to 8 notes whose displayed title contains the text after `[[` (case-insensitive; `list_notes` filtered in the app, no `search_notes` on main). `Up`/`Down` move, `Enter` or a click picks, `Esc` cancels. The key bindings only apply while the popup is open (`LinkPicker > Input` context), so `Enter` otherwise inserts a newline |
| 7 | Link format | Core `format_note_link(title, id)` gives `[Title](bourbon://note/<id>)`, escaping `\`, `[`, `]` and turning line breaks into spaces; `parse_note_link(url)` returns the `NoteId` for a well-formed `bourbon://note/<id>`. The app passes `display_title` so an empty title becomes `Untitled`. The editor auto-closes brackets, so `[[` arrives as `[[]]`; picking also consumes up to two `]` right after the cursor |
| 8 | Opening links | Preview link click goes to `Workspace::open_link`. `bourbon://note/<id>`: flush the pending save, load the note; missing or trashed shows the error banner and keeps the open note; a note not in the current listing switches the navigation to All Notes; then it is selected like any list click. Every other URL goes to `cx.open_url` |
| 9 | Find and replace | The gpui-component code editor already has a search panel (match count, next/previous, replace, replace all, `Esc` closes). Reused as is: `Ctrl+F` and `Ctrl+H` open it when the body is focused. App-level `FindInNote` / `ReplaceInNote` actions (same keys, no context) cover the title field and Preview mode: they switch Preview to Edit (Side-by-side keeps its mode), focus the body and open the panel. No match logic of our own |
| 10 | Focus mode | `Ctrl+Shift+F` toggles, `Esc` also exits (the `Esc` binding propagates when not in focus mode). It only stops rendering the sidebar and note list and caps the editor column at 720 px, centred; the sidebar's own visible flag is untouched, so it is restored exactly. `Ctrl+/` is ignored while in focus mode |
| 11 | Word count | Footer under the editor: `N words · M characters`. Words are runs of Unicode whitespace-separated tokens (`split_whitespace`), characters are `chars().count()` of the body, newlines included |
| 12 | Control pane | `control_pane/` is not on main yet; the new actions (`CycleViewMode`, `FindInNote`, `ReplaceInNote`, `ToggleFocusMode`, `ToggleTaskAtCursor`) are plain GPUI actions ready to be listed there |

Code: `crates/bourbon-app/src/editor/` (`tasks`, `preview_blocks`, `link_trigger`, `link_picker`, `word_count`, `view_mode` pure; `preview`, `toolbar` views), `workspace/writing_intents.rs`, `bourbon-core/src/note_link.rs`.
