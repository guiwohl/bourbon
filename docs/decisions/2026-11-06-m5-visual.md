# M5 Visual: settings, themes, resizable panes

Scope: functional part only. Animations and polish are left to the UI pass.

## Settings

- `bourbon-core::settings`: `Settings` in `$XDG_CONFIG_HOME/bourbon/settings.toml`, fallback `~/.config/bourbon/settings.toml`.
- Fields: `theme_source` (`bourbon` | `omarchy`, default bourbon), `appearance` (`light` | `dark`, default light, ignored when following Omarchy), `sidebar_visible` (true), `sidebar_width` (160-400, default 200), `note_list_width` (220-560, default 260).
- Missing file or bad text gives defaults; each invalid field falls back alone. Widths are clamped on load and on set. Saves are atomic (temp file in the same directory, then rename).
- `editor_view_mode` (`edit` | `side_by_side` | `preview`, default edit) is persisted: the `ViewMode` enum lives in core; the app loads it at startup and saves on every change.
- Backup fields are added when the backup UI arrives, not before.

## Bourbon theme

Two palettes matching Inkdrop 6 (light: sidebar `#ebebee`, list and editor `#f7f7f8`, border `#dedee2`, text `#1f2024`, muted `#6f7078`, accent `#3d7be0`, list selection `#d6dfeb`, sidebar selection `#d8d8de`; dark: cool slate, sidebar `#1f2228`, list and editor `#262a31`, border `#343944`, text `#d7dae0`, muted `#8a909c`, accent `#5b9bf0`, selection `#2f3d52`), Light is the default appearance. Status icon colours (blue `#3d7be0`, orange `#f0a020`, green `#2fb36a`, red `#e5534b`) live in `icons.rs`, tag pills tint the tag colour. Markdown syntax-highlight colours belong to the editor column and are not part of the palette yet, kept as data in `bourbon-app/src/theme/palette.rs` and painted onto gpui-component's `Theme` colors.

## Follow Omarchy

- `~/.local/state/omarchy/current/theme/colors.toml` (`$XDG_STATE_HOME` first). Core parses it (`OmarchyColors`, needs background, foreground, accent, selection, color1, color8).
- Mapping: background, foreground and accent as given; muted foreground from color8; danger from color1; sidebar, border and muted are the background mixed 5%, 18% and 9% toward the foreground; selection is the background mixed 40% toward `selection` (a raw selection color is too strong as a row background). Text on the accent is black or white by accent luminance.
- Light or dark comes from background luminance (below 0.5 is dark).
- A missing or invalid file falls back silently to the Bourbon palette in the chosen appearance.
- Live update: a GPUI timer checks the file's mtime every 2 s and re-applies on change.

## Panes

- No gpui-component resizable panel was used; a 4 px drag handle (`panes::Divider`) sits after the sidebar and after the note list. Drag moves update widths in memory (clamped); settings are saved on mouse up.
- Ctrl+/ saves `sidebar_visible` immediately.

## Settings screen

`Ctrl+,` (or the "Open settings" control pane action) replaces the editor column with the settings view: Theme (Bourbon / Follow Omarchy) and Appearance (Light / Dark, inert and dimmed while following Omarchy). Changes apply and save immediately. "Back to notes" or opening a note leaves it. There is no Escape binding to avoid clashing with the editor and control pane.

## Tests never touch the real config

`Locations` (settings file and Omarchy colors path) is injected into `Workspace`; headless tests use temp directories.
