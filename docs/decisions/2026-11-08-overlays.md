# 2026-11-08 — Overlays on bourbon-ui

Follows [2026-11-07-ui-rebuild.md](2026-11-07-ui-rebuild.md). Values from [inkdrop-ui-shell.md](../research/inkdrop-ui-shell.md) 3.8 to 3.13.

| # | Topic | Decision | Why |
|---|---|---|---|
| 1 | Primitives | New in `bourbon-ui`: `Modal`, `Dialog`, `Checkbox`, `Select`, `ButtonVariant::Danger`, `Shadows::modal` / `palette`. Only GPUI | Every overlay needed a modal layer, a dialog frame, a destructive button and form controls |
| 2 | Inputs | Every overlay input is `bourbon_editor::TextField`; it gained `masked`, `borderless` and `text_size` | One input everywhere; the token must stay hidden, the palette input is large and bare |
| 3 | Control pane | Inkdrop telescope look: modal 56 px from the top, 48 px input row, rows with icon slot, detail line, accessory, 3 px info bar, footer hints, "No results found"; hover highlights | Research 3.11 |
| 4 | Settings | Inkdrop preferences layout (160 px page menu + content) replacing the three columns while open; pages General and Backup; selects, checkbox, text fields | Inkdrop uses a separate window; full width inside the main window keeps one window and gives the content room. Single window kept for single-instance and focus behaviour |
| 5 | Dialogs | One `Dialog` at a time from `Workspace::dialog`: sidebar name / delete prompt, restore, empty trash. Enter confirms, Esc and backdrop cancel | Research 3.9; replaces the inline sidebar panel, the inline restore box and the gpui-component alert |
| 6 | Not matched | Modal animations, focus restore to the previous element, page-menu icons, the telescope icon (search icon used), modifier-dependent footer actions | GPUI has no CSS transitions; icons are not in our Lucide set yet |
| 7 | Tests | Overlays keep the element ids the tests click (`overlay::tagged` / `layer`) | Behaviour tests stay as they were |

## What still depends on `gpui-kit`

- Editor column (title input, header pickers, preview, link picker): replaced by PR #38.
- App test harness: moved to GPUI (`debug_selector` + `VisualTestContext`), see [app.md](../architecture/app.md#test-harness); what is left there only serves the editor column.
- `window.rs` (`gpui_kit::init`, `open_window` with `Root`), `assets.rs` (gpui-component icons), `theme/` (gpui-component `Theme`), `presentation::chip_color` (`ColorName`): all for the editor column.
